About the System

This system uses Machine Learning and URL-based feature analysis to identify potentially phishing URLs and estimate their associated risk.

🤖

Machine Learning

A Random Forest classification model analyzes URL characteristics to classify URLs as phishing or legitimate.

🔍

URL Analysis

The system extracts features such as URL length, subdomains, digits, special characters and HTTPS usage.

🛡️

Risk Assessment

The model probability is converted into a risk score and risk level to make the result easier to understand.
